Proje Dosyaları

Ajanın oluşturduğu ya da senin yüklediğin dosyalar burada tutulur. GitHub sekmesinden bir depoya işleyebilirsin.

Henüz dosya yok.

GitHub Entegrasyonu

Kişisel erişim jetonun (PAT) yalnızca bu cihazda saklanır, hiçbir sunucuya gönderilmez — doğrudan tarayıcından GitHub API'sine gider.

Ayarlar → Developer settings → Fine-grained tokens (repo okuma/yazma izniyle)

Vercel Entegrasyonu

Vercel API token'ınla bağlı projeyi yeniden dağıtabilir ya da dağıtım durumunu izleyebilirsin.

vercel.com/account/tokens adresinden oluşturabilirsin

Ollama Cloud Ayarları

Ajan, kod üretimi için Ollama Cloud üzerindeki modelleri kullanır.

ollama.com → Settings → API keys adresinden alınır
Örnekler: gpt-oss:120b-cloud, gpt-oss:20b-cloud, qwen3-coder:480b-cloud, deepseek-v3.1:671b-cloud
